Version 3.6

Version 3 completely overhauled the overall website experience. From there, we've made changes that aren't quite enough to be in another full version number, so we've combined the features in one log. We've added these new features since version 3.0 came out:

Themes: Don't like the default color scheme? You can now choose between a generous selection of different themes to make your experience more personalized to you.

Updating Homework: The homework popup is now easier to access right from one button on the navbar, and the process has been redesigned to look and feel easier to use.

Subjects: Fixed a few issues regarding subject spacing and certain types of overflow situations.

Settings: The settings page is more compact and slightly redesigned to look better.

Changelog: Added a changelog that explains new features.

Mobile: Changed mobile layout to prevent overflow and allow for content to fit on the screen better.

Proctor View: Current proctor is now a toggleable view from the "more" button on the bottom of the screen.

Welcome screen: Shows username, if applicable, but also eases transition to saved theme during page loading.

Points: Added points for crossing off subjects. May experience glitches as this feature is not perfect.

Alternate Viewing Modes: Changed alternate viewing modes in settings to show maximum content on small screens.

Compact Navigation: All navigation buttons can be hidden. This is especially useful for smaller devices.

Foreign Language: Changed grid behavior to accomodate FL subjects without taking too much space; may continue to add things related to this feature.

This version will likely be the last major update for a while. The main goals for the next update are better code readability and optimization. Please give feedback if there's anything else you want to see us add!

Updates may cause theme corruption. This is an easy fix and only requires you to re-select your preferred theme if you are impacted.
